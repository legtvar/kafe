# Pi Extension: GitLab Issues Integration

This project includes a custom Pi extension for GitLab issues integration.

## What's Included

A project-scoped extension that enables Pi to read and interact with GitLab issues from this repository.

### Features

✅ **List Issues** - Fetch all open/closed issues with filtering  
✅ **Search Issues** - Search by keywords in titles and descriptions  
✅ **Get Issue Details** - Retrieve full details of specific issues  
✅ **Autocomplete** - Type `!` followed by numbers/text for quick issue references  
✅ **Auto-detection** - Automatically detects GitLab repositories  

### Tools Available

1. **`gitlab_list_issues(state?, search?, limit?)`**
   - List issues with optional filters
   - Example: `gitlab_list_issues({ state: "opened", search: "bug" })`

2. **`gitlab_get_issue(issue_id)`**
   - Get details of a specific issue
   - Example: `gitlab_get_issue({ issue_id: 123 })`

## Usage

Simply start Pi in this directory and the extension will load automatically.

```bash
pi
```

You'll see a notification: "GitLab Issues extension loaded for legtvar/kafe"

Then you can:
- Ask Pi to list or search issues
- Use autocomplete by typing `!` 
- Reference issues naturally in conversations

## Authentication (Optional)

For private repositories or increased rate limits, set one of these environment variables:

```bash
export GITLAB_TOKEN=your_token_here
# or
export GL_TOKEN=your_token_here
# or
export GITLAB_CI_TOKEN=your_token_here
```

## Reloading Extensions

After making changes to the extension, reload it in Pi:

```
/reload
```
